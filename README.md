### Régimen de aprobación

\
La materia es **promocionable**.
Para aprobar el curso se necesita:

- Cumplir con las entregas obligatorias de ejercicios seleccionados de las guías.
- Aprobar las entregas de TPs del Laboratorio.
- Aprobar el prefinal correspondiente al teórico/práctico.

La nota resultará del promedio ponderado de estas instancias: 10% corresponde a las entregas, 60% a los TPs de Laboratorio y 30% al prefinal.
